# ecommerce-Kaua-Perraro

PROJETO E-COMMERCE - PARTE I

O que e o projeto

iStore: landing page responsiva de uma loja virtual de iPhones
(iPhone 14, 15, 15 Pro, 15 Pro Max, 16, 16 Pro e 16 Pro Max).
Produtos e precos sao ficticios.

Tecnologias

- HTML5 semantico (header, nav, main, section, footer)
- CSS externo, Mobile First (breakpoints de 768px e 1024px), com Flexbox e Grid
- JavaScript basico: menu que abre e fecha, calculo de frete (if/else)
  e validacao do formulario de contato

Como abrir

1. Baixe ou clone a pasta projeto-ecommerce.
2. Abra o arquivo index.html 
   
Estrutura

projeto-ecommerce/
  index.html
  css/style.css
  js/script.js
  img/ (imagens dos 7 iPhones)
